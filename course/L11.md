### 定时任务卡模板（第 11 课｜定时任务 · Grok Bot 上手课）

> 这里只写 Grok Bot 文档里写了的，或者我们录课时亲眼看到的（标「实测」）。文档说「可能」的地方，这里也写「可能」。

#### 1. 建之前先确认六件事（文档）
| # | 问题 | 你的答案 |
|---|---|---|
| 1 | 哪个 Bot 负责？ | |
| 2 | 时间表和时区？（设置 →「通用」→ Bot 一栏的「时区」） | |
| 3 | 从哪里拿输入？ | |
| 4 | 交付成什么样、交到哪里？ | |
| 5 | 哪些事必须先问我？（发送、购买、删除、发布、改线上） | |
| 6 | 数据没有 / 过期时怎么办？ | |

#### 2. 说明模板（直接改了发给负责的 Bot）
```
帮我建一个定时任务，名字叫「＿＿」：
- 时间：每＿＿ ＿＿:＿＿（＿＿时间）
- 输入：读 ＿＿（只读，不改）
- 做法：用技能「＿＿」（做法写在技能里，这里不抄步骤）
- 交付：只在这个对话里回 / 存成 ＿＿ 文件；不发邮件、不发消息，不发给任何人
- 先问我：发送、购买、删除、发布、改线上的东西之前，一律先停下问我
- 没数据：输入不存在、是空的或不是当天的，直接告诉我「今天没有数据」，不拿旧数据凑
- 只做完一部分：在这个对话里说清做到哪、卡在哪
建好后告诉我下次什么时候跑。
```

#### 3. 先试一遍，看五样（文档说：每次运行都会真的干活，所以用安全输入）
- 怎么试：在对话里跟负责的 Bot 说，用同样的安全输入（比如演示文件）把这套做法先做一遍，做完给你看结果。
- ☐ 拿的是不是当天的新输入
- ☐ 格式对不对
- ☐ 有没有留下可追查的记录
- ☐ 该停下问我的地方停了没有
- ☐ 失败时有没有说清楚
- 第一次正式跑完，也照这五样看一遍。

#### 4. 在哪儿建，就在哪儿查、在哪儿管
- 入口（实测，2026-10-03 桌面版录屏）：点对话顶部的 **Bot 名** → 右侧打开它的**信息栏** → 『**详情**』标签 → **例行任务**。再点一次 Bot 名，信息栏就收起。
- 信息栏上面三个标签：『详情』『资料库』『电脑』。例行任务在『详情』里；资料库放它的文件；电脑能看到它电脑的画面。
- 本课说的定时任务，中文界面叫「例行任务」，英文界面叫 Routine。
- 在对话里建的，也列在『详情』的例行任务里（实测：X管家 在对话里建的「X 单次发帖 10/3 20:30」，列表里就有这一条，标着「仅一次」）。每条写着什么时候跑，旁边有开关。
- **建之前先去『详情』看一眼有没有同名任务，别重复建。**

#### 4.5 建完核对，在对话里改、暂停、删除
- 建完先在对话里核对（实测）：让负责的 Bot 列出现有的定时任务——名字、时间、状态（开着还是暂停）、下次运行时间，写明「只回答，不要改动任何东西」。再去『详情』对一遍，对得上才算建好；对不上先问负责的 Bot，别急着再建一个。
- 改：直接跟负责的 Bot 说，改完同样让它复述，再去『详情』核对（录课没有演示修改）。
- 暂停 / 删除：直接跟 Bot 说「暂停 / 删除某某」（实测：对话里出现 Disabled routine / Deleted routine 标记）。停完、删完同样去『详情』核对。
- 删除：删了不能撤销；删掉 Bot，它的定时任务一起删掉。暂时不用的，先暂停。
- 上限：文档说每个 Bot 最多 50 个定时任务。
- 手机：文档说 Bot 资料页能看时间表，也能暂停、恢复或删除；编辑要回到电脑版。

#### 5. 没按时跑？文档给的排查顺序
1. 是否开着
2. 时间表和时区
3. 负责的 Bot 还在不在
4. 插件是否已登录
5. 输入能不能访问
6. 用量或账号有没有被暂停
- 你长时间不在时，Grok Bot 可能会问要不要继续运行；没回应可能会先暂停。

#### 6. 额度小账
- 文档说：试用额度按 Bot 干活的步骤和用到的内容量算，不按消息条数；活越大越长，用得越多。
- 文档说（cursor.com 帮助 Routines）：每跑一次都花额度；每小时跑、间隔很短、或 Slack 触发盯着很忙的频道，可能一天用掉一周的额度。从没运行过的定时任务不花额度。
- 在对话里先试一遍，它是真的在干活，所以**也一样会花**。
- 新建的定时任务要等到下一个排定时间才跑，不会建好就马上跑。
- 每次用量 × 次数：每小时一次 = 一天 24 次。频率按真实需要定。
- 事件触发别设太宽（文档说：会带来噪音、消耗用量，更容易对无关输入动手）。
- 不用先暂停，确定不要再删除。按工作量分层省额度 → 第 12 课。

#### 6.5 你不在时的审批
- 文档说（cursor.com 帮助「Why did an approval expire?」）：定时任务、触发器、别的 Bot 发来的消息这类你不在场时开始的工作，审批卡大约 10 分钟没批就过期，这一步不执行。
- 做法：给跑定时任务的 Bot 打开**通知**（文档说：桌面在这个 Bot 的设置里，手机在 Bot 资料页）；过期了就让 Bot 重新做一次。

#### 7. 一句话分工
技能 = 怎么做；定时任务 = 何时、谁来做。只做一次的事，直接派活。

#### 8. 第一次怎么上手
在对话里建好，让 Bot 复述说明和下次运行时间，再去『详情』核对；第一次跑完看结果，再决定留不留。
