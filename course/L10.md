### 连接前检查清单（第 10 课｜连上工具 · Grok Bot 上手课）

> 这里只写 Grok Bot 文档（docs.x.ai/grok-bot、cursor.com/help/grok-bot、cursor.com/docs/grok-bot，2026-09-30 抓取）里写了的；标「这一版看到的」是录课时在桌面版上看到的（英文界面和中文界面 0.66.0 都有）；标「我们的建议」是本课程自己的做法。

#### 1. 连之前，问自己四个问题（我们的建议）
1. 这件活**真的需要**连这个工具吗？（文档说：只连这件活需要的工具）
2. 用哪个账号？能不能用**权限受限的专用账号**？（文档说：服务支持的话就用）
3. 第一件活能不能是**只读**的、只出**草稿**？
4. 哪些动作必须先问我？（发送、发布、购买、删除、改线上 → 写进派活单，见第 9 课）

#### 2. 三种连法
| 连什么 | 怎么连 | 要记住 |
|---|---|---|
| 服务（Gmail、日历、Slack、Notion…） | 插件 | 装好的插件，账号下**所有 Bot** 都能用 |
| 没有插件的网站 | 打开 Bot 的电脑，自己登录 | Bot 看不到你输入的密码；登录状态所有 Bot 共用 |
| 你自己的电脑 | 本机执行（中文界面「在这台电脑上执行」，英文界面 Execution on this computer） | 文档说默认每条命令都先问你 |

#### 3. 添加插件（文档步骤）
1. 侧栏点 **Plugins**（docs.x.ai 叫 Marketplace），或点对话里的 **Connect** 卡片；手机：左上角头像 → Plugins。
2. 浏览或搜索 → **Add**。
3. 要求 **Authorize / Authenticate** 时，在浏览器里登录。
4. 确认它出现在 **Installed** 里。
5. 对话里输入 `@`，把它带进任务。
- 这一版看到的：英文界面侧栏是 **Plugins**；中文界面侧栏是「**连接应用**」，打开后标题是「**市场**」，按钮是「**添加**」。插件详情页分 **Connectors** 和 **Skills** 两栏；分类里有「MCP」（个人版文档没讲 MCP）。

#### 4. 授权：它能做的不会超过这个账号（文档）
- 插件只能做授权账号本来就能做的事；不能提高权限，不能改共享设置。
- 登录令牌（OAuth）存在 Cursor 的连接后端，Bot 调用工具时拿不到它。
- Slack：以你连上的用户身份发消息，只在这个用户能发的频道里发。
- Gmail：搜、读、起草、发送、加标签；一次只能连一个邮箱。
- 公司 Google 账号卡在授权页：要管理员批准「Grok」；换浏览器、重新连解决不了。
- 这一版看到的（Google Calendar，中文界面）：「添加」→ 账户显示「需要认证」→「身份验证」→ 浏览器里 Google 授权页勾选权限 → Continue →「授权完成」→ 回到 Grok Bot 显示「已连接」。没勾权限就点 Continue 会被拒绝，回 Grok Bot 点「重试」。
- 我们的建议：日历授权页上读写两项都有；授权读写都有，派活单里只让它读，再加「改日历先问我」（设置「通用」→「自动审核规则」：Grok Bot 要在日历里新建、修改或删除日程时 → 先询问）。

#### 5. 重新授权：按状态来（文档）
| 看到 | 做 |
|---|---|
| Added（Bot 说用不了） | Added 只是装好，不等于已登录 → 打开插件看状态 |
| Needs auth / Disconnected | **Authorize**，重新登录 |
| Waiting for authorization | **Reopen**，把登录页找回来 |
| 授权没完成 / 失败 | **Retry**；约 10 分钟内在浏览器里登完 |
| Connected | 给 Bot 发条新消息，让它再试 |
| 还不行 | **Remove**，重新添加再登录；仍不行联系支持 |
| 在服务那边撤销过授权 | 先移除插件，再重新连接 |
- 文档说点 **Authorize**；这一版看到的：英文界面 Installed 列表里没登录的插件旁边是 **Authenticate** 按钮，登好的显示绿色 **Connected**；中文界面是「需要认证」「身份验证」「重试」「已连接」。

#### 6. 定时任务的事件触发（第 11 课会用）
- 文档说：Cursor 账号的集成可以在事件发生时启动定时任务（Slack 消息、GitHub 通知等），和 Slack / GitHub 插件是两回事。
- 依赖 Slack 触发之前，先在**拥有这个 Bot 的 Cursor 账号**上连好 Slack。
- 怎么连：文档指到「Connect plugins」那一页；连好以后，还要让 Bot 在定时任务里建触发。
- 频道和关键词设窄；太宽会一直触发、花额度。

#### 7. 你自己的电脑（本机执行）
- 文档说：通过桌面 App，Bot 可以在你电脑上跑命令、读文件、在云电脑和本机之间搬文件。
- 设置位置：文档说，还没登记电脑 → Settings → General → Bot → **Execution on Local Computer**；登记后 → Settings → **Computer**，每台电脑一项 **Execution on this computer**。这一版看到的（中文界面）：设置 →「**电脑**」，每台电脑一项「**在这台电脑上执行**」。
- 选项：「**每次询问**」（文档说是默认）／「**始终允许**」／「**从不允许**」；英文界面 Ask every time／Always allow／Never allow。建议：先选「**从不允许**」；要让它在你电脑上跑命令时，再改成「**每次询问**」。
- 本机命令卡（这一版看到的）：「允许 Grok Bot 及所有 Bot 在你的本地电脑上运行命令吗？」按钮「**始终允许**／**允许一次**／**从不**」；要跑的命令收在「**查看命令**」里。
- 团队管理员可设上限，团队更严时以团队为准。
- 日历这类插件动作的卡是另一张：「**审核操作**」卡，标「需要批准」，完整请求在「查看完整请求」里，按钮「**允许一次**」「**拒绝**」；拒绝后显示「操作已拒绝」。
- 这些设置不影响 Bot 用它自己的云电脑。

#### 8. 令牌、密码、收回（文档）
- 密码、验证码不发在普通聊天里；需要时打开 Bot 的电脑，接管画面自己输。
- 支持的连接会弹出**安全密钥请求**：输入被遮住，不进聊天记录，模型看不到。
- 在 Bot 电脑上登录的网站，所有 Bot 都能用；某个 Bot 不该用的账号，就别登。
- 不用了：暂停或删除相关定时任务 → 退出 Bot 电脑上的网站登录 → 卸载插件并到服务那边撤销授权 → 清掉 /workspace 里的敏感文件。
- 定期检查装了哪些插件、开着哪些定时任务。

#### 9. 新手第一个连接（我们的建议）
- 挑一个天天用、只读就有用的服务，比如日历。
- 第一件活：「看看我明天有哪些会，列个表。不要改任何日程，不要回复邀请。」
- 本机执行先选「从不允许」；要让它在你电脑上跑命令时，再改成「每次询问」。
